JSON Outline Schema is one piece of the larger HAX ecosystem of specs and schemas. Explore the others below.

*   [hax-schema](https://haxtheweb.github.io/hax-schema/) — HAX property schemas that define how web components integrate with the HAX authoring interface.
*   [hax-element-schema](https://haxtheweb.github.io/hax-element-schema/) — the schema format for describing individual HAX-capable elements.
*   [merlin-schema](https://haxtheweb.github.io/merlin-schema/) — the schema behind Merlin, HAX's AI assistant integration.
*   [appstore-spec](https://haxtheweb.github.io/appstore-spec/) — the specification for the HAX app store, used to register and discover HAX-compatible apps and services.

New to HAX itself? [Get started at haxtheweb.org](https://haxtheweb.org/) to learn about the HAX authoring experience, install the CLI, and build your first HAXsite.
